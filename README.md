# Библиотека TrioZ — этап 1

Согласованный перенос приложенного Next.js-проекта на управляемый стек Runable: Bun, React/Vite, Hono; инфраструктура Drizzle из шаблона. База библиотеки, админка и импорт RTF **не реализованы** — это следующие этапы.

## Запуск

Нужен Bun версии из `package.json` (`packageManager`).

```bash
bun install --frozen-lockfile
bun run dev
```

Web-порт задан в `__ports.cjs` → `.runable/ports.json` (в этом проекте 4200). В управляемой среде его не изменять.

```bash
bun run build
bun run lint
bun run typecheck
```

`bun run build` проверяет TypeScript, собирает Web и заготовку Desktop. Мобильное приложение не разрабатывалось и отдельной сборки мобильного приложения нет. `bun run build:web` собирает только Web. Обе команды сохраняют 33 кадра анимации и исходное разрешение большой карты после стандартной оптимизации ассетов.

Команды `dev`, `build`, `build:web`, `start`, `stop`, `lint`, `typecheck` сохранены как контракт управляемого шаблона. `bun run start` использует штатный PM2-конфиг. `.env` из рабочей среды не включён в архив: это защита секретов. Инфраструктурные настройки создаются средой Runable; база на этапе 1 сайту не нужна. Публикация управляемого сайта — через интерфейс платформы. Инструкция независимого nginx-деплоя относится к согласованию этапа 8 и сейчас не выдается как проверенная.

## Ограничения этапа 1

Тексты пока по-прежнему хранятся в коде. Это специально: база и перенос в неё будут отдельными этапами. Метаданные обновляются в браузере, не через Next.js SSR. Старый редирект клиентский, не HTTP 301. Экран 404 показывается клиентом; HTML-оболочка неизвестного URL возвращает HTTP 200. Полноценные серверные метаданные, статусы, sitemap и SEO требуют отдельной реализации на управляемом стеке.

Сборка успешна, но Vite предупреждает о JS-чанке больше 500 kB и Node — о deprecated `module.register()`. Это предупреждения, не ошибки. Разбиение чанков оставлено для полировки.

## Повторная проверка

Для стандартной проверки достаточно `bun run build`, `bun run lint`, `bun run typecheck` и ручных шагов из отчёта.

`scripts/migrate-stage1.py` — **одноразовый** скрипт, не команда обновления сайта: при повторном запуске перезапишет перенесённые файлы. `scripts/verify-stage1.py` сравнивает страницы с распакованным исходным архивом в `/home/user/trioz-original`, проверяет браузером порт 4200; требует Python + Pillow + Playwright и Chrome. `scripts/download-fonts.py` нужен только для повторного скачивания шрифтов, требует httpx, fonttools и brotli; для сборки он не запускается, шрифты уже включены.
